## 路由文件定义规则

相较于传统的路由定义方式，本项目创新性地采用了文件目录自动扫描技术来识别并生成路径。因此，传统的route文件不再需要，项目入口（page）目录下的所有文件夹都将被自动识别并纳入路由系统。这一改变旨在确保路由配置与文件结构的一致性，同时，也有助于简化菜单权限的管理与过滤。为此，我们特别编写了此说明文件，详细阐述路由文件的生成规则。

```
<route lang="yaml">
meta:
  layout: default // 定义文件的布局方式，默认为 default 格式，如果有其他布局方式，请在src/layouts/文件夹内 重新声明
  index: 1-2 // 此菜单的显示顺序，用连字符区分一级/二级菜单的顺序
  name: xxx名称-xxx名称 // 此菜单的名称，用连字符区分一级/二级菜单的名称
  hideBg: true // 不显示背景色
  hidden: true // 当前文件不在路由内显示
</route>

<template></template>

<script></script>
```
